# Amritsar Clock Tower Concept

A stylized 3D clock tower concept created in Blender, inspired by modern monument architecture and urban landmark design. The project features a central clock structure, symmetrical elevated walkways, geometric forms, and a clean cinematic presentation with vibrant orange and pink accents.

## Features

* Unique modern clock tower design
* Stylized architectural composition
* Symmetrical elevated platform structure
* Illuminated digital clock display
* Decorative gemstone centerpiece
* Urban monument-inspired aesthetics
* Clean geometric modeling workflow
