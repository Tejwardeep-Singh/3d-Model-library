# 3D Model Library

A curated collection of custom 3D models created in Blender, including renders and export-ready assets in GLB and FBX formats.

---

## Repository Structure

```txt
3d-model-library/
│
├── model-name/
│   ├── model.glb
│   ├── model.fbx
│   ├── render1.png
│   ├── render2.png
│   └── README.md
│
└── README.md
```

---

## Included Formats

- `.glb` — Recommended for web and Three.js projects
- `.fbx` — Compatible with Unity, Unreal Engine, and other 3D software
